Streaming multiprocessor (SM): 
Lorsqu'on lance la fonction kernel : Chaque threads vont être assigné à un SM. tous les threads d'un block au même.
sûrement que plusieurs blocs seront assigné au même SM.
la SM possède une mémoire partagé (on chipp)
différente de la off chipp (VRAM) beaucoup plus grosse. (mais plus loin). donc plus longue (utilisation de la bandwith)

Memory Coalescence
la SM possède des Warps  warps qui peuvent chacun exécuter 32 threads. elle va éxécuter la même instruction pour tous les threads.
la SM possède une mémoire in-chip.
Pour éxécuter le programme in-chip va chercher l'élement de la off-chip (long. processus) puis exécuter les instruction (rapide).
Elle ne peut pas aller chercher les élements de la off-chip en parallèle sauf si des threads consécutif doivent aller chercher des index mémoire consécutifs.

Shared Memory
Shared Memory : commun au bloc, 16KB / SM
Registers : unique au threads, 8KB/ thread
L'objectif est donc de donner à nos Shared memory des données qui sont stockées
 sur la shared memory et qui peut être utilisés par les autres threads du même block pour éviter de communiquer avec la VRAM
